`cfg://`: this application's settings; use it only when the user asks about them or asks to change them. `cfg://<ns>` is a namespace, and `cfg://<ns>/<key>` gives a value, type, default, and source. A write sets the value for the session only, and `…/save` persists it; writes need user approval (an unanswered prompt is an error, so move on). After a session-only write, ask whether to save.
