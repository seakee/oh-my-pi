Generate or edit images with the configured image-model role.

## Usage

- Write one detailed `subject` for the generation or edit.
- With several `input` images, say what each one contributes in `subject` (for example, `Image 1` for composition and `Image 2` for lighting).
- Set `model` only when a specific catalog model is required.
- For text, ask for "sharp, legible, correctly spelled" text and keep it short.
