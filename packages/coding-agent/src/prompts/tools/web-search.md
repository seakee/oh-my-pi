Known URLs and programmatic data belong to `read`.
Query syntax: `site:` or `-site:`, `after:` or `before:` `YYYY-MM-DD`, `inurl:`, `intitle:`, `filetype:`, `"phrase"`, `-term`, `OR`.
{{#if xSearch}}
X posts and reactions → `site:x.com`, `site:x.com/<handle>`, or `from:<handle>`; `-from:<handle>` excludes.
{{/if}}
Hacker News stories and comments → `site:news.ycombinator.com`.
Prefer primary sources and cite every source with a link.
