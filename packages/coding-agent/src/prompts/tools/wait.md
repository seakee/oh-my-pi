Wait only when you are blocked with nothing else to do.
It blocks on background jobs or services you started, or on the reply to a message you sent this run, and returns on the first result, a message sent to you, or a steering interrupt; a safety cap returns a snapshot of what is still running.
When nothing you started is running and no reply is owed, it returns at once.
Results and messages auto-deliver, so never poll while work remains.
